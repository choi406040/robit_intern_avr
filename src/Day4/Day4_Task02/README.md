## 1. 개요 (Overview)
본 과제는 ATmega128의 ADC(가변저항), 외부 인터럽트(스위치), 타이머/카운터를 조합하여
**날짜·시간을 직접 세팅하고 실시간으로 흘러가는 디지털 달력/시계**를 구현하는 것을 목표로 함.

### 핵심 목표
* 가변저항(ADC) 값을 각 시간 단위(연/월/일/시/분/초/1/100초)의 범위로 스케일링하여 세팅
* 외부 인터럽트(SW1)로 세팅 항목을 순차 확정, SW2로 시간 흐름 시작
* Timer0 오버플로우 인터럽트를 이용한 1ms 주기 시간 누적 및 자릿수 올림(캐리) 처리
* 월별 일수(31/30/28일) 구분 등 날짜 예외처리

## 3. 하드웨어 구성 및 핀 맵 (Hardware Structure)

### Pin Configuration

```text
[ATmega128]                 [Target Component]
 PF0 (ADC0)          ----->   가변저항 (세팅 값 입력, 0~1023)
 PE4 (INT4)          ----->   SW1 : 세팅 항목 확정 / 다음 항목으로 이동
 PE5 (INT5)          ----->   SW2 : 시간 흐르기 시작 (Timer0 구동)
 PD0 (SCL) / PD1(SDA)----->   I2C Text LCD (연-월-일 / 시-분-초 출력)
```

### 주요 회로 특징
* **전원:** 5V DC 안정화 전원 공급
* **스위치:** `PORTE |= (1<<4)|(1<<5);` 로 내부 풀업 사용, **하강 에지(Falling Edge)** 트리거
* **ADC 기준전압:** AVCC 기준 (`ADMUX = 0x40`), 분주비 128 (`ADCSRA = 0x87`)
* **주의사항:** ISP 다운로드 시 SPI 핀 타겟 전원 및 리셋 회로 간섭 주의

## 5. 핵심 코드 및 레지스터 설정 (Key Implementation)

### 5.1 주변장치 초기화 (`set()`)
```c
void set (void){
    DDRE = 0x00;                    // PE4, PE5 입력(스위치)
    PORTE |= (1<<4)|(1<<5);         // 내부 풀업 활성화
    DDRF = 0x00;                    // PF0 입력(가변저항)

    EIMSK = 0b00110000;             // INT4, INT5 인터럽트 허용
    EICRB = 0x0A;                   // INT4, INT5 하강 에지 트리거

    ADMUX  = 0x40;                  // AVCC 기준, ADC0 채널 선택
    ADCSRA = 0x87;                  // ADC Enable, 분주비 128 (16MHz/128 = 125kHz)

    SREG = 0x80;                    // 전역 인터럽트 허용
}
```

### 5.2 가변저항 값 → 시간 단위 스케일링
`timetable[7]` 배열에 `{년, 월, 일, 시, 분, 초, 1/100초}` 순으로 저장하며,
`timetable_count`가 가리키는 항목만 ADC 값에 따라 실시간으로 변한다.

| index | 항목 | 스케일링 식 | 범위 |
| :---: | :--- | :--- | :--- |
| 0 | 연(하위 2자리) | `ADC * 100 / 1024` | 0 ~ 99 |
| 1 | 월 | `ADC * 12 / 1024 + 1` | 1 ~ 12 |
| 2 | 일 | 월에 따라 `*31 / *30 / *28` 후 `+1` | 1 ~ 31 |
| 3 | 시 | `ADC * 24 / 1024` | 0 ~ 23 |
| 4 | 분 | `ADC * 60 / 1024` | 0 ~ 59 |
| 5 | 초 | `ADC * 60 / 1024` | 0 ~ 59 |
| 6 | 1/100초 | `ADC * 100 / 1024` | 0 ~ 99 |

> `(long)ADC * 100 / 1024` 형태로 캐스팅한 이유는 `int`(16bit)에서
> `1023 * 100 = 102300`이 오버플로우되기 때문임.

### 5.3 Timer0를 이용한 1ms 타이밍 (SW2 입력 시 구동)
```c
ISR(INT5_vect){          // SW2 : 시간 흐르기 시작
    TCNT0 = 6;
    TCCR0 = 0x04;        // 분주비 64
    TIMSK = 0x01;        // Timer0 Overflow 인터럽트 허용
}

ISR(TIMER0_OVF_vect){
    count1ms++;
    if (count1ms == 10){ // 1ms × 10 = 10ms → 1/100초 단위 증가
        timetable[6]++;
        sort_time_tabel();
        count1ms = 0;
    }
    TCNT0 = 6;           // 다음 1ms를 위한 초기값 재설정
}
```
**타이밍 계산:** 16MHz / 64 = 250kHz (1 tick = 4µs) → `TCNT0 = 6`부터 시작해
256까지 250 tick 카운트 → **250 × 4µs = 1ms** 주기 오버플로우 발생

### 5.4 자릿수 올림 및 날짜 예외처리 (`sort_time_tabel()`)
1/100초 → 초 → 분 → 시 → 일 → 월 → 연 순으로 캐리를 전파하며,
일(日) 처리 시 해당 월의 최대 일수를 구분함.

```c
if (월 == 1,3,5,7,8,10,12) { if (일 >= 32) { 일 = 1; 월++; } }  // 31일
else if (월 == 2)          { if (일 >= 29) { 일 = 1; 월++; } }  // 28일
else                       { if (일 >= 31) { 일 = 1; 월++; } }  // 30일
if (월 >= 13) { 월 = 1; 연++; }
```

### 5.5 LCD 출력 포맷
```text
1행 :  YY MM DD          (ex. 19 07 22)
2행 :  hh:mm:ss.cc       (ex. 10:50:48.34)
```
`sprintf(temp, "%02d", ...)`로 2자리 0-패딩 후 `i2c_lcd_goto_XY()`로 좌표를 지정해 출력함.

## 6. 동작 설명 및 결과 (Results)

### 동작 시나리오
1. 전원 인가 → `set()`으로 ADC / 외부 인터럽트 / 스위치 초기화, `i2c_lcd_init()`으로 LCD 초기화
2. 가변저항을 돌리면 현재 세팅 중인 항목(`timetable_count`) 값이 LCD에서 실시간으로 변함
3. **SW1**을 누를 때마다 `INT4` 인터럽트 발생 → 현재 값 확정, 다음 항목으로 이동
   (연 → 월 → 일 → 시 → 분 → 초 → 1/100초)
4. 모든 세팅 완료 후 **SW2**를 누르면 `INT5` 인터럽트 발생 → Timer0 구동, 시간이 흐르기 시작
5. 10ms마다 1/100초가 증가하고, 자릿수가 넘어갈 때마다 상위 단위로 올림 처리됨
